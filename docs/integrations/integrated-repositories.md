# Integrated Repositories

Third-party repositories and projects integrated into the Agent Guidance MCP codebase.

---

## Bundled Content & Remote Updates

Integrated repositories are bundled into the binary and can be updated from their upstream remote repositories at any time via:

```bash
agent-guidance --update
```

|---|---|---|
