# Integrated Repositories

Third-party repositories and projects integrated into the Agent Guidance MCP codebase.

---

## Bundled Content & Releases

Integrated skills and standards are curated and bundled directly into the binary and distributed with each release. They are synchronized to `~/.agent-guidance/skills` upon installation/setup and when upgrading via:

```bash
agent-guidance --upgrade
```

| Repository | Role | License |
|---|---|---|
| [ECC v2.0.0](https://github.com/affaan-m/ECC) | 168-skill catalog — backend, frontend, testing, security, DevOps, data, research, and 12+ language ecosystems. | MIT |
| [andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills) | 6 core coding principles (Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven Execution, DRY, Code Organization). | MIT |
| [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | UI/UX design data — palettes, fonts, landing patterns, charts, slide strategies. | MIT |
| [anthropics/skills](https://github.com/anthropics/skills) | 17+ skill catalog — creative & design, development & technical, enterprise & communication. | Apache 2.0 |
| [OWASP Cheat Sheets](https://github.com/OWASP/CheatSheetSeries) | ~100 security cheat sheets — SQL injection, XSS, CSRF, auth, cryptography, MCP security, AI agent security, and more. | CC BY-SA 4.0 |
