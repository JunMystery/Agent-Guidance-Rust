# AI Image Generation Prompts (16:9 Widescreen & Clean Doodle Style Guide)

This document contains standardized, anti-hallucination image prompts for Midjourney v6, DALL-E 3, and Flux to generate graphics for `README.md`.

---

## 🎨 Unified Design & Style System (Clean Doodle Aesthetic)

All image generation prompts follow this **Clean Doodle Design Guide**:

- **Visual Style**: Minimalist clean hand-drawn doodle vector illustration, smooth thin black outlines, modern tech doodle aesthetic, spacious pastel fill, zero visual clutter.
- **Color Palette**: Off-white/cream minimalist paper background (`#F8F9FA` or dark slate mode), soft pastel cyan, indigo blue, lavender, and vibrant accent pops.
- **Negative Prompting (Anti-Hallucination)**: `no text, no blurry labels, no unreadable handwriting, no gibberish words, no photorealistic elements, no complex 3D render, no messy chaos`.
- **Aspect Ratio**: **`16:9` Widescreen Landscape** (`--ar 16:9`).
